Bioassay LOD Fitter is a web application built to analyse concentration-response data, perform advanced sigmoidal curve fitting, and rigorously calculate the Limit of Detection (LOD) for diagnostic assays using validated statistical frameworks.

- **Live Demo:** [akshamsabadi.github.io/bioassay-LOD-fitter](https://akshamsabadi.github.io/bioassay-LOD-fitter/)
- **Source Code:** [akshamsabadi/bioassay-LOD-fitter](https://github.com/akshamsabadi/bioassay-LOD-fitter)

### Features

- Completely client-side processing (no server uploads needed)
- Interactive Data Entry for calibration standards and blank measurements
- Advanced Curve Fitting automatically selects between 4PL and 5PL models
- Interactive logarithmic plot displaying data points, modelled curve, 95% CI, and critical limits ($L_C$, $L_D$, and LOD)
- High-Resolution Export to download publication-ready PNGs
